# Nash-Cooperative Swarm Intelligence for Lightweight Edge Learning Through Multi-Team Adaptive Optimization

## Project Overview

This repository contains the complete experimental pipeline for the paper:

**“Nash-Cooperative Swarm Intelligence for Lightweight Edge Learning Through Multi-Team Adaptive Optimization”**

The project develops a lightweight organizational intelligence framework for disability-risk and functional-health prediction using NHANES data. The framework combines:

- Multi-team organizational learning
- Nash-cooperative optimization
- Swarm-based adaptive cooperation
- Specialist-team explainability
- Lightweight edge-oriented inference
- Temporal external generalization analysis

The entire pipeline was designed to maintain strict consistency between:
- methods,
- preprocessing,
- modeling,
- explainability,
- optimization,
- efficiency evaluation,
- and temporal validation.

---

# Scientific Workflow

The project follows the exact logical sequence described in the paper methods section:

1. Data acquisition and preprocessing
2. Missing-data harmonization
3. Modeling-ready dataset generation
4. Organizational internal learning
5. Specialist-team explainability
6. Swarm-based cooperative adaptation
7. Lightweight edge-efficiency evaluation
8. Temporal organizational generalization

The experiments were intentionally designed as a connected methodological stream rather than isolated independent tests.

The repository demonstrates that:
- lightweight multi-team organizational intelligence,
- combined with Nash-cooperative swarm adaptation,
- can preserve balanced predictive behavior under multidomain health conditions,
- while remaining computationally efficient for edge-oriented deployment.

**Nash-cooperative swarm intelligence for lightweight adaptive edge learning.**

### Statistical Validation Module

`experiment6_statistical_validation.py` provides the formal statistical validation layer for the proposed organizational healthcare intelligence framework. This module performs 5-fold stratified cross-validation with repeated random seeds, reports mean ± standard deviation with 95% confidence intervals, and conducts paired significance testing between cooperation strategies. The generated outputs directly support the statistical validation and reproducibility analyses reported in the manuscript.
### Fairness and Uncertainty Analysis

`FairnessUncertaintyAnalysis.py` performs subgroup fairness evaluation and predictive uncertainty analysis on the internal NHANES testing cohort. The script reports demographic subgroup performance across sex, age, and race/ethnicity when available, together with calibration metrics including Expected Calibration Error (ECE), Maximum Calibration Error (MCE), and Brier score. These outputs support the fairness-consistency and uncertainty reporting presented in the manuscript.
