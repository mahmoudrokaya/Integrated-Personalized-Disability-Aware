## Dataset Description

### Internal Dataset
The internal organizational-learning dataset consists of pooled NHANES survey cycles from **2011–2018**, including:

- 2011–2012
- 2013–2014
- 2015–2016
- 2017–2018

These data were used for model development, training, validation, and internal testing.

---

### External Temporal Dataset
The external temporal evaluation dataset consists of harmonized later NHANES releases collected after the internal development period, including:

- **2017–March 2020 Pre-Pandemic**
- **2021–August 2023**

These later-cycle datasets were used exclusively for temporal external validation and organizational generalization analysis under distribution shift and partial-observation conditions.

---

### Note
Repository preprocessing utilities also include scripts for exploring broader post-2018 NHANES releases (including future release portals), but the experiments reported in the manuscript use only the cycles described above.
